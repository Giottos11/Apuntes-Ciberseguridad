# Posibles especializaciones

La especialización no tiene que elegirse al principio. Una buena base permite cambiar de dirección sin perder los conocimientos adquiridos.

## Red Team / Pentesting

Reconocimiento, enumeración, explotación, post-explotación, movimiento lateral y Active Directory.

## Blue Team / SOC

Logs, monitorización, SIEM, detección y respuesta a incidentes.

## Purple Team

Combina conocimientos ofensivos y defensivos.

## Web Security

HTTP, JavaScript, APIs, SQL, autenticación y Burp Suite.

## Malware Analysis

Sistemas, Windows internals, C y reverse engineering.

## Reverse Engineering

C, ensamblador, binarios, memoria y debugging.

## Cloud Security

AWS, Azure, IAM, identidades y redes cloud.

## Identity / Active Directory Security

Windows, Active Directory, Kerberos, LDAP, NTLM y GPO.

## Mobile Security

Android e iOS.

## AI Security

Seguridad de sistemas y aplicaciones basados en inteligencia artificial.

## IoT / Hardware Security

Sistemas embebidos, hardware, firmware y comunicaciones.

## OT/ICS Security

Seguridad de sistemas industriales y de control.

## Security Engineering

Diseño, implementación y operación de sistemas seguros.

## Regla general

Primero desarrollar conocimientos transversales y utilizar proyectos y laboratorios para descubrir qué especialización resulta más interesante.

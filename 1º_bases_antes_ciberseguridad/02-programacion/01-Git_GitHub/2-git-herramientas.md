# Git, GitHub y herramientas

## Git/GitHub

- Repositorio
- Commit
- Branch
- Merge
- Clone
- Push
- Pull
- `.gitignore`
- README

Git permite gestionar el historial de un proyecto y trabajar con diferentes versiones del código.

## Principio

La herramienta es secundaria respecto al conocimiento que permite aplicar. No se trata de memorizar comandos de cientos de herramientas, sino de comprender las técnicas y saber seleccionar la adecuada.

## Principio general

La especialización puede cambiar con el tiempo. Por eso conviene construir primero una base transversal:

**Informática → Programación → Git → Linux → Redes → Windows → Web → Ciberseguridad → Especialización**

Red Team es una posible dirección, pero esta base permite cambiar posteriormente hacia Blue Team, Purple Team, seguridad web, malware, ingeniería inversa, cloud security, etc.

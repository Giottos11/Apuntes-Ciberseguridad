# Criptografía

## Objetivo

Comprender los principios utilizados para proteger información y comunicaciones.

### Hashes
- Hash
- SHA-2
- MD5
- Salt

MD5 debe estudiarse también para comprender por qué no debe utilizarse como función de hash criptográfica segura para nuevos sistemas.

### Integridad y autenticación
- HMAC

### Cifrado simétrico
- AES

### Cifrado asimétrico
- RSA
- ECC

### Comunicaciones
- TLS
- Certificados
- PKI

## Principio

Es más importante comprender qué problema resuelve cada mecanismo, qué propiedades ofrece y cuándo se utiliza que memorizar cada algoritmo.

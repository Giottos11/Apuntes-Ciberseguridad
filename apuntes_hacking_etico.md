# Apuntes de Hacking Ético

## 1. Hacking ético

### Definiciones y términos básicos

-   **Navegación anónima:** es cuando navegas por Internet sin que se
    nos pueda identificar como fuente de las pruebas.
-   **Hacking:** es un tipo de persona que usa las técnicas de hacking
    por motivos políticos para protestar en el ámbito digital (como
    Anonymous).
-   **Script Kiddie:** aquellas personas que no tienen conocimiento
    técnico y que solo usa el hacking que se pueda lanzar directamente
    (botón gordo).
-   **Sniffers:** hardware o software que nos permite obtener el tráfico
    de red.
-   **Hash:** forma de transformar un texto de longitud variable a uno
    de longitud fija.
-   **Ingeniería social:** forma o técnicas de engañar o forzar a una
    persona a realizar una determinada acción o comportamiento.
-   **Phishing:** es el envío de correos fraudulentos suplantando a
    alguien.
-   **Intrusión física:** es cuando estamos realizando algún tipo de
    prueba en el ámbito físico.

## 2. Seguridad integral

La seguridad integral es un concepto que nos permite integrar la
seguridad digital, la seguridad física y la seguridad en las personas.

### Principio del mínimo privilegio

Un usuario no debe tener más privilegios de los que necesita para
realizar correctamente su labor.

### Defensa en profundidad

Consiste en implantar una serie de capas y poner todas las capas que
podamos entre el riesgo y el activo.

### Bitcoin

Es una criptomoneda y una moneda distribuida que no depende de ningún
país ni entidad bancaria.

### Deep Web

Es la web profunda que no está directamente accesible a través de
buscadores. Para acceder a determinados servicios pueden utilizarse
herramientas como Tor.

## 3. Técnicas de ataque

**Vulnerabilidad:** es un fallo en software o hardware que puede
permitir obtener cierto privilegio.

**Exploit:** permite aprovechar una vulnerabilidad.

## 4. Ataque de fuerza bruta

**Ataque de fuerza bruta:** consiste en realizar múltiples intentos para
conseguir acceder a un sistema, por ejemplo mediante un programa que
pruebe contraseñas.

### Denegación de servicio (DoS)

Ataque que provoca que un servicio deje de funcionar o no pueda
proporcionar correctamente el servicio a los clientes.

### Denegación de servicio distribuido (DDoS)

Ataque en el que muchos equipos se conectan a un mismo servicio con el
objetivo de saturar sus recursos.

### Spam

Envío masivo de correos con el objetivo de molestar o saturar.

### Phishing

Envío de correos fraudulentos suplantando a alguien.

### Vishing

Técnica de ingeniería social realizada mediante llamadas telefónicas.

## 5. Malware

### Bot

Equipo que ha sido comprometido y cuyo control puede ser tomado por un
atacante.

### Botnet

Red formada por múltiples bots bajo el control de un atacante.

### Rootkit

Software que permite ocultar la presencia del atacante dentro de un
sistema.

### Ransomware

Tipo de malware cuyo objetivo es extorsionar al usuario.

### CryptoLocker

Ejemplo de ransomware que cifra el disco y solicita un rescate.

### Spyware

Tipo de malware que espía el comportamiento del usuario.

### Troyano

Software que permite obtener control remoto del equipo comprometido.

### Virus

Malware que puede replicarse y extenderse.

### Gusano

Malware similar a un virus que puede propagarse sin necesidad de
interacción del usuario.

## 6. Introducción al Hacking Ético

### Nociones básicas

La seguridad debe contemplarse desde diferentes ámbitos:

-   **Ámbito físico**
-   **Ámbito digital**
-   **Ámbito humano**

Estos ámbitos forman parte de la seguridad integral.

### Acciones por ámbito

#### Ámbito físico

-   Análisis perimetral de seguridad.
-   Identificación de accesos alternativos.
-   Evasión de controles RFID/NFC.
-   Evasión de controles biométricos.
-   Evaluación de sistemas embebidos.
-   Análisis de redes wireless.
-   Control remoto de CCTV.
-   Análisis de entornos industriales.

#### Ámbito digital

-   Anonimización de las comunicaciones.
-   Análisis de sistemas perimetrales.
-   Análisis de servicios públicos.
-   Intrusión y control de dominios internos.
-   Control de sistemas industriales.
-   Control de sistemas Mainframe.
-   Desarrollo de exploits propios.

## 7. Ingeniería social

### Definición

Técnicas utilizadas para engañar o forzar a una persona a realizar una
determinada acción o comportamiento.

### Pretexting

Creación de una situación o historia falsa para conseguir que una
persona revele información o realice una acción.

### Phishing

Técnica de ingeniería social mediante correos, páginas web o mensajes
fraudulentos.

### Vishing

Técnica de ingeniería social realizada mediante llamadas telefónicas.

### Baiting

Consiste en dejar un dispositivo o recurso aparentemente atractivo para
conseguir que una persona interactúe con él.

### Tailgating

Consiste en aprovecharse de una persona autorizada para acceder a una
zona restringida entrando detrás de ella.

## 8. Auditoría de seguridad

### Definición

Una auditoría de seguridad consiste en evaluar sistemas, aplicaciones,
redes y procedimientos para identificar vulnerabilidades y riesgos.

### Objetivos

-   Identificar vulnerabilidades.
-   Evaluar controles de seguridad.
-   Comprobar el cumplimiento de políticas.
-   Detectar riesgos.
-   Proponer medidas correctoras.

## 9. Tipos de enfoques

### Black Box

La prueba se realiza sin disponer de información previa sobre el
sistema.

### White Box

Se dispone de toda la información sobre el sistema antes de realizar las
pruebas.

### Gray Box

Se dispone de información parcial sobre el sistema.

## 10. Vectores de ataque

Los vectores de ataque son las diferentes vías que puede utilizar un
atacante para comprometer un sistema.

Ejemplos:

-   Vulnerabilidades de software.
-   Vulnerabilidades de hardware.
-   Ingeniería social.
-   Ataques a aplicaciones web.
-   Ataques a redes.
-   Ataques físicos.
-   Malware.
-   Credenciales comprometidas.

## 11. Dispositivos de seguridad

### IDS --- Intrusion Detection System

Sistema de detección de intrusos encargado de detectar accesos no
autorizados o comportamientos potencialmente maliciosos.

### HIDS

Sistema de detección de intrusiones basado en host. Analiza la actividad
de un equipo concreto.

### NIDS

Sistema de detección de intrusiones basado en red. Analiza el tráfico de
una red para detectar posibles ataques.

## 12. De cualquier interacción realizada

La información obtenida de cualquier interacción realizada puede
utilizarse para analizar el comportamiento y detectar posibles
anomalías.

### Sistemas de detección

Los sistemas de detección pueden analizar diferentes tipos de
información para identificar comportamientos sospechosos o ataques.

## 13. Metodologías de seguridad

### Introducción

La seguridad debe abordarse mediante una metodología estructurada que
permita identificar riesgos, analizar vulnerabilidades, realizar pruebas
y aplicar medidas correctoras.

### Seguridad integral

La seguridad integral considera conjuntamente:

-   Seguridad física.
-   Seguridad digital.
-   Seguridad humana.

El objetivo es conseguir una protección global de la organización y de
sus activos.

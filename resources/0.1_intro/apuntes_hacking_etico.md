## Definiciones y términos básicos

**Navegación anónima:** es cuando navegas por Internet sin que se nos pueda identificar como fuente de las pruebas.

**Hacking:** es un tipo de persona que usa las técnicas de hacking por motivos políticos para protestar en el ámbito digital (como Anonymous).

**Script Kiddie:** aquellas personas que no tienen conocimiento técnico y que solo usa el hacking que se pueda lanzar directamente (botón gordo).

**Sniffers:** hardware o software que nos permite obtener el tráfico de red.

**Hash:** forma de transformar un texto de longitud variable a uno de longitud fija. Es como la firma de este texto.

**Ingeniería social:** forma o técnicas de engañar o forzar a una persona a realizar una determinada acción o comportamiento.

**Phishing:** es el envío de correos fraudulentos suplantando a alguien.

**Intrusión física:** es cuando estamos realizando algún tipo de prueba en el ámbito físico.

# Dispositivos de seguridad

> Viernes 16 de enero de 2026

## Firewall

Un firewall es un software, hardware o combinación de ambos que generalmente se utiliza para separar una red protegida de una pública y no protegida.

Estos dispositivos tienen la capacidad de monitorizar y filtrar el tráfico entrante o saliente para prevenir el acceso no autorizado a las redes protegidas.

## Red desmilitarizada (DMZ)

Una zona desmilitarizada o DMZ, también llamada red perimetral, es una red aislada intermedia entre Internet y la red interna de la organización.

El objetivo de una DMZ es que las conexiones desde la red interna y la externa estén permitidas, mientras que en general las conexiones desde la DMZ solo se permitan a la red externa y no la interna.

## Honeypot

Un Honeypot es un equipo explícitamente desplegado para atraer a aquellas personas que penetran en la red de la organización.

Estos sistemas emulan servicios especialmente atractivos que buscarían unos atacantes que hayan accedido a la red.

# De cualquier interacción realizada

## Sistemas de detección de intrusos (IDS)

Un sistema de detección de intrusos o IDS es un software o hardware encargado de detectar accesos no autorizados o comportamientos potencialmente maliciosos en un sistema o red.

Estos sistemas suelen tener sensores o sondas como pueden ser equipos con sensores de red encargados de recopilar el tráfico de red y enviarlo al sistema central para que lo analice y detecte posibles amenazas.

## Firewall de aplicación web (WAF)

Un firewall de aplicación o WAF es un dispositivo hardware o software que tiene como objetivo analizar el tráfico web entre el servidor de diversas páginas web y la WAN, protegiendo el servidor de ataques web como SQL Injection, Cross-Site Scripting, etc.

## Data Lost Prevention (DLP)

Un sistema de prevención de pérdida de datos o DLP es un software o hardware diseñado para enfriar el tráfico de red y evitar la exfiltración de información sensible como pueden ser usuarios y contraseñas, documentos con información bancaria, etc.
